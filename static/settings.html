Service Actions & Standalone Scripts

You can control the background service directly from this panel or use the native script files generated in your project folder:

Generated Standalone Scripts:
start_background.vbs: Silent VBScript launcher — double click to launch windowless.
start_background.bat: Windows batch launcher for background execution.
stop_background.bat: Stops any background process listening on port 5000.
install_service.bat: Direct installer script to register autostart on Windows.
uninstall_service.bat: Direct script to remove autostart from Windows.
